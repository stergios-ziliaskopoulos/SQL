Βοήθεια
Γράψε ένα ή περισσότερα ερωτήματα χωρισμένα με ; και πάτα Εκτέλεση. Εμφανίζεται το αποτέλεσμα του καθενός.

Οι αλλαγές (INSERT, UPDATE, DELETE) ισχύουν μόνο σε αυτή τη συνεδρία — «Επαναφορά βάσης» τα σβήνει όλα και ξαναχτίζει τα αρχικά δεδομένα. Χάλασέ την ελεύθερα.

Σε εξωτερικό πληκτρολόγιο: Ctrl/Cmd + Enter για εκτέλεση.
