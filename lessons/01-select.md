# Μάθημα 1 — Τι είναι η SQL και το πρώτο σου `SELECT`

## Στόχος

Να καταλάβεις τι είναι μια σχεσιακή βάση και να διαβάζεις δεδομένα από έναν πίνακα.

---

## 1.1 Πίνακες, γραμμές, στήλες

Μια **σχεσιακή βάση δεδομένων** είναι ένα σύνολο από **πίνακες**. Κάθε πίνακας μοιάζει με φύλλο Excel:

- **στήλες** (columns) = τα πεδία, με σταθερό όνομα και τύπο (`title` κείμενο, `price` αριθμός)
- **γραμμές** (rows) = οι εγγραφές, μία ανά βιβλίο/πελάτη/παραγγελία

Η βάση μας έχει 8 πίνακες. Δες τους:

```
python3 sql.py
sql> .tables
sql> .schema books
```

Η **SQL** (Structured Query Language) είναι η γλώσσα με την οποία ζητάς δεδομένα. Το σημαντικό:
**δηλώνεις τι θέλεις, όχι πώς θα βρεθεί**. Το «πώς» το αποφασίζει η βάση.

---

## 1.2 Το πρώτο ερώτημα

```sql
SELECT * FROM books;
```

- `SELECT` → ποιες στήλες θέλω
- `*` → «όλες τις στήλες»
- `FROM books` → από ποιον πίνακα
- `;` → τέλος εντολής

Δοκίμασέ το:

```
python3 sql.py "SELECT * FROM books;"
```

Το `*` είναι βολικό στην εξερεύνηση, αλλά στην πράξη **ζήτα μόνο ό,τι χρειάζεσαι**:

```sql
SELECT title, price FROM books;
```

Λιγότερα δεδομένα ταξιδεύουν, και το ερώτημα δεν «σπάει» αν κάποιος προσθέσει στήλη αργότερα.

---

## 1.3 Ψευδώνυμα (aliases) με `AS`

Μετονομάζεις στήλες στο αποτέλεσμα:

```sql
SELECT
    title AS τίτλος,
    price AS τιμή
FROM books;
```

Το `AS` είναι προαιρετικό (`price τιμή`), αλλά γράψ' το — διαβάζεται πολύ καλύτερα.
Αν το ψευδώνυμο έχει κενά, θέλει διπλά εισαγωγικά: `AS "Τιμή σε ευρώ"`.

> **Προσοχή στα εισαγωγικά**
> - `'κείμενο'` → μονά εισαγωγικά για **τιμές κειμένου**
> - `"όνομα"` → διπλά εισαγωγικά για **ονόματα στηλών/πινάκων**
>
> Το `WHERE title = "Ποιήματα"` είναι λάθος συνήθεια που κάποιες βάσεις σου συγχωρούν και κάποιες όχι.

---

## 1.4 Υπολογισμοί μέσα στο `SELECT`

Το `SELECT` δεν επιστρέφει μόνο αποθηκευμένες στήλες — υπολογίζει κιόλας:

```sql
SELECT
    title,
    price,
    price * 1.24 AS τιμή_με_ΦΠΑ,
    stock * price AS αξία_αποθέματος
FROM books;
```

Λειτουργούν οι συνήθεις τελεστές `+ - * /` και η ένωση κειμένου με `||`:

```sql
SELECT first_name || ' ' || last_name AS ονοματεπώνυμο
FROM customers;
```

---

## 1.5 Μορφοποίηση που θα σε σώσει

Η SQL αγνοεί τα κενά και τις αλλαγές γραμμής. Εκμεταλλεύσου το:

```sql
-- Έτσι, όχι σε μία ατέλειωτη γραμμή
SELECT
    title,
    price
FROM books;
```

Σχόλια: `-- μέχρι το τέλος της γραμμής` ή `/* πολλών γραμμών */`.

Οι λέξεις-κλειδιά (`SELECT`, `FROM`) γράφονται συμβατικά με **κεφαλαία** και τα ονόματα
πινάκων/στηλών με μικρά. Δεν είναι υποχρεωτικό — η SQL δεν ξεχωρίζει κεφαλαία/μικρά στις
λέξεις-κλειδιά — αλλά βοηθά το μάτι.

---

## 1.6 Η σειρά που *γράφεις* δεν είναι η σειρά που *εκτελείται*

Γράφεις: `SELECT … FROM … WHERE … GROUP BY … HAVING … ORDER BY … LIMIT`

Εκτελείται:

```
FROM  →  WHERE  →  GROUP BY  →  HAVING  →  SELECT  →  ORDER BY  →  LIMIT
```

Κράτα το — εξηγεί δύο πράγματα που μπερδεύουν τους πάντες:

- γιατί **δεν** μπορείς να χρησιμοποιήσεις ψευδώνυμο του `SELECT` μέσα στο `WHERE`
  (το `WHERE` τρέχει πριν υπάρξει το ψευδώνυμο)
- γιατί **μπορείς** να το χρησιμοποιήσεις στο `ORDER BY` (τρέχει μετά)

```sql
-- ✗ Λάθος: το τιμή_με_ΦΠΑ δεν υπάρχει ακόμα όταν τρέχει το WHERE
SELECT price * 1.24 AS τιμή_με_ΦΠΑ FROM books WHERE τιμή_με_ΦΠΑ > 20;

-- ✓ Σωστό
SELECT price * 1.24 AS τιμή_με_ΦΠΑ FROM books WHERE price * 1.24 > 20;

-- ✓ Σωστό επίσης — το ORDER BY τρέχει μετά το SELECT
SELECT price * 1.24 AS τιμή_με_ΦΠΑ FROM books ORDER BY τιμή_με_ΦΠΑ DESC;
```
