# Μάθημα 12 — Oracle: τι αλλάζει

## Στόχος

Να μεταφέρεις ό,τι έμαθες σε **Oracle Database**, που είναι το RDBMS στο οποίο στηρίζονται
οι εταιρικές αναφορές (BusinessObjects, JasperReports, Qlik πάνω από Oracle).

Η λογική δεν αλλάζει σε τίποτα: `SELECT`, `JOIN`, `GROUP BY`, window functions, όλα ίδια.
Αλλάζουν οι **συναρτήσεις** και μερικές συμπεριφορές. Αυτό το μάθημα είναι ο χάρτης.

> ⚠️ Τα ερωτήματα αυτού του μαθήματος **δεν τρέχουν** στην SQLite του project. Είναι για
> ανάγνωση, μετάφραση και αναφορά. Αν θέλεις να εξασκηθείς πραγματικά, το Oracle Live SQL
> (livesql.oracle.com) δίνει δωρεάν περιβάλλον μέσα από τον browser — δουλεύει και από κινητό.

## 12.1 Ο συγκεντρωτικός πίνακας αντιστοίχισης

| Θέλω | SQLite (το μάθημα) | Oracle |
|---|---|---|
| Ερώτημα χωρίς πίνακα | `SELECT 1;` | `SELECT 1 FROM dual;` |
| Αν είναι κενό, βάλε… | `COALESCE(x, 0)` | `NVL(x, 0)` — και το `COALESCE` δουλεύει |
| if/else | `CASE WHEN…` | `CASE WHEN…` ή `DECODE(x, 1, 'a', 2, 'b', 'άλλο')` |
| Σημερινή ημερομηνία | `DATE('now')` | `SYSDATE` |
| Κείμενο → ημερομηνία | (κείμενο παντού) | `TO_DATE('2025-01-31', 'YYYY-MM-DD')` |
| Ημερομηνία → κείμενο | `STRFTIME('%Y-%m', d)` | `TO_CHAR(d, 'YYYY-MM')` |
| Έτος | `STRFTIME('%Y', d)` | `EXTRACT(YEAR FROM d)` |
| Αρχή μήνα | `DATE(d,'start of month')` | `TRUNC(d, 'MM')` |
| Πριν 12 μήνες | `DATE(d,'-12 months')` | `ADD_MONTHS(d, -12)` |
| Διαφορά σε μήνες | (υπολογισμός) | `MONTHS_BETWEEN(a, b)` |
| Πρώτα Ν | `LIMIT 10` | `FETCH FIRST 10 ROWS ONLY` (12c+) |
| Σελιδοποίηση | `LIMIT 10 OFFSET 20` | `OFFSET 20 ROWS FETCH NEXT 10 ROWS ONLY` |
| Διαφορά συνόλων | `EXCEPT` | **`MINUS`** |
| Ένωση κειμένων ομάδας | `GROUP_CONCAT(x, ', ')` | `LISTAGG(x, ', ') WITHIN GROUP (ORDER BY x)` |
| Εισαγωγή ή ενημέρωση | `INSERT … ON CONFLICT` | `MERGE INTO … USING …` |
| Αυτόματο id | `INTEGER PRIMARY KEY` | `GENERATED BY DEFAULT AS IDENTITY` (12c+) ή sequence |
| Λίστα πινάκων | `sqlite_master` | `USER_TABLES`, `ALL_TAB_COLUMNS` |
| Πλάνο εκτέλεσης | `EXPLAIN QUERY PLAN` | `EXPLAIN PLAN FOR …;` + `DBMS_XPLAN.DISPLAY` |

## 12.2 Πέντε συμπεριφορές που θα σε εκπλήξουν

### 1. Το κενό κείμενο **είναι** `NULL`

```sql
SELECT CASE WHEN '' IS NULL THEN 'ναι' ELSE 'όχι' END FROM dual;   -- ναι
```

Στην Oracle το `''` και το `NULL` είναι το ίδιο πράγμα. Σε PostgreSQL/SQLite είναι
διαφορετικά. Κάθε έλεγχος `WHERE σχόλιο = ''` δεν θα βρει ποτέ τίποτα.

### 2. Τα `NULL` πάνε **τελευταία** σε αύξουσα σειρά

Ακριβώς αντίθετα από την SQLite. Στην Oracle το `NULL` θεωρείται το μεγαλύτερο:

```sql
ORDER BY country              -- τα NULL στο ΤΕΛΟΣ
ORDER BY country DESC         -- τα NULL στην ΑΡΧΗ
ORDER BY country NULLS LAST   -- ρητά, και δουλεύει και στις δύο κατευθύνσεις
```

Αν μια αναφορά «άλλαξε σειρά» μετά από μετάπτωση βάσης, συνήθως αυτό φταίει.

### 3. Το ψευδώνυμο **δεν** χρησιμοποιείται στο `GROUP BY`

Αυτό επηρεάζει άμεσα τον κώδικα των προηγούμενων μαθημάτων:

```sql
-- ✓ SQLite    ✗ Oracle
SELECT STRFTIME('%Y-%m', order_date) AS μήνας, SUM(x) FROM … GROUP BY μήνας;

-- ✓ Oracle: επανάλαβε την έκφραση…
SELECT TO_CHAR(order_date, 'YYYY-MM') AS μήνας, SUM(x)
FROM …
GROUP BY TO_CHAR(order_date, 'YYYY-MM')
ORDER BY μήνας;              -- στο ORDER BY το ψευδώνυμο επιτρέπεται

-- …ή, καθαρότερα, βάλ' το σε CTE
WITH βάση AS (
    SELECT TO_CHAR(order_date, 'YYYY-MM') AS μήνας, ποσό FROM …
)
SELECT μήνας, SUM(ποσό) FROM βάση GROUP BY μήνας ORDER BY μήνας;
```

Το δεύτερο μοτίβο δουλεύει **παντού** — και στην SQLite. Αν θέλεις κώδικα που μεταφέρεται,
γράφε έτσι εξαρχής.

### 4. Το `ROWNUM` εφαρμόζεται **πριν** το `ORDER BY`

Η κλασικότερη παγίδα της Oracle σε παλιό κώδικα:

```sql
-- ✗ Δίνει 5 ΤΥΧΑΙΕΣ γραμμές και μετά τις ταξινομεί
SELECT title, price FROM books WHERE ROWNUM <= 5 ORDER BY price DESC;

-- ✓ Ταξινόμησε πρώτα, φίλτραρε μετά
SELECT * FROM (SELECT title, price FROM books ORDER BY price DESC) WHERE ROWNUM <= 5;

-- ✓✓ Ή, σε 12c και μετά, απλά:
SELECT title, price FROM books ORDER BY price DESC FETCH FIRST 5 ROWS ONLY;
```

### 5. Τα ονόματα γίνονται **κεφαλαία**

Το `CREATE TABLE Books` δημιουργεί πίνακα `BOOKS`. Αν τον γράψεις `"Books"` με διπλά
εισαγωγικά, μένει ακριβώς έτσι — και από εκεί και πέρα πρέπει να τον γράφεις πάντα με
εισαγωγικά. **Μη χρησιμοποιείς ποτέ εισαγωγικά σε ονόματα αντικειμένων.**

Πρακτικό συμπέρασμα και για τα ελληνικά ψευδώνυμα του μαθήματος: σε πραγματικό έργο, ονόμασε
πίνακες και στήλες με **λατινικούς χαρακτήρες, πεζά, χωρίς κενά**. Τα ελληνικά εδώ βοηθούν στη
μάθηση· σε παραγωγή δημιουργούν προβλήματα με εργαλεία, drivers και κωδικοποιήσεις.

## 12.3 Ημερομηνίες — εδώ είναι όλη η διαφορά

Στην Oracle ο τύπος `DATE` περιέχει **και ώρα** (μέχρι δευτερόλεπτο). Αυτό γεννά το πιο
συχνό λάθος σε αναφορές:

```sql
-- ✗ Χάνει τις παραγγελίες της 31/1 μετά τις 00:00:00
WHERE order_date BETWEEN TO_DATE('2025-01-01','YYYY-MM-DD')
                     AND TO_DATE('2025-01-31','YYYY-MM-DD');

-- ✓ Ανοιχτό δεξιά — δουλεύει πάντα, με ή χωρίς ώρα
WHERE order_date >= TO_DATE('2025-01-01','YYYY-MM-DD')
  AND order_date <  TO_DATE('2025-02-01','YYYY-MM-DD');
```

Ο κανόνας `>= αρχή AND < επόμενη αρχή` είναι σωστός σε **κάθε** βάση. Συνήθισέ τον.

Χρήσιμα:

```sql
TRUNC(SYSDATE)                          -- σήμερα, 00:00:00
TRUNC(order_date, 'MM')                 -- πρώτη του μήνα  → ιδανικό για GROUP BY
TRUNC(order_date, 'IW')                 -- Δευτέρα της εβδομάδας
LAST_DAY(order_date)                    -- τελευταία του μήνα
ADD_MONTHS(TRUNC(SYSDATE,'MM'), -12)    -- ίδιος μήνας πέρσι
order_date + 1                          -- αύριο (η αριθμητική είναι σε ημέρες)
(d2 - d1)                               -- διαφορά σε ημέρες, ως αριθμός
EXTRACT(YEAR FROM order_date)
TO_CHAR(order_date, 'DD/MM/YYYY HH24:MI')
```

**Ποτέ μη βασίζεσαι στην προεπιλεγμένη μορφή** (`NLS_DATE_FORMAT`) — αλλάζει ανά σύνδεση και
ανά χρήστη. Γράψε πάντα ρητά `TO_DATE(..., 'YYYY-MM-DD')`.

## 12.4 Ιεραρχίες: `CONNECT BY`

Η Oracle υποστηρίζει το τυπικό `WITH RECURSIVE` (από 11gR2), αλλά ο παλιός της τρόπος είναι
πολύ πιο σύντομος και θα τον συναντήσεις παντού:

```sql
SELECT
    LEVEL                                   AS επίπεδο,
    LPAD(' ', (LEVEL - 1) * 3) || name      AS οργανόγραμμα,
    SYS_CONNECT_BY_PATH(name, ' / ')        AS διαδρομή
FROM employees
START WITH manager_id IS NULL
CONNECT BY PRIOR id = manager_id
ORDER SIBLINGS BY name;
```

- `START WITH` → η ρίζα
- `CONNECT BY PRIOR γονέας = παιδί` → ο κανόνας σύνδεσης
- `LEVEL` → το βάθος, δωρεάν
- `CONNECT_BY_ROOT name` → η ρίζα κάθε κλάδου

Σύγκρινέ το με το αναδρομικό CTE του Μαθήματος 6 — ίδιο αποτέλεσμα, το ένα τέταρτο του κώδικα.

## 12.5 `MERGE`: το upsert της Oracle

Καρδιά κάθε ETL — «ενημέρωσε αν υπάρχει, πρόσθεσε αν δεν υπάρχει»:

```sql
MERGE INTO dim_customer d
USING (SELECT id, first_name || ' ' || last_name AS full_name, city FROM customers) s
   ON (d.customer_key = s.id)
WHEN MATCHED THEN
    UPDATE SET d.full_name = s.full_name,
               d.city      = s.city
WHEN NOT MATCHED THEN
    INSERT (customer_key, full_name, city)
    VALUES (s.id, s.full_name, s.city);
```

Αυτό ακριβώς τρέχει κάθε νύχτα για να ανανεώνει τις διαστάσεις ενός data warehouse.

## 12.6 Analytics — τα ίδια, με μερικά δώρα

Όλα τα window functions του Μαθήματος 7 δουλεύουν αυτούσια. Επιπλέον:

```sql
SELECT
    category_id,
    title,
    price,
    RATIO_TO_REPORT(price) OVER (PARTITION BY category_id) AS μερίδιο,
    LISTAGG(title, ', ') WITHIN GROUP (ORDER BY title)
        OVER (PARTITION BY category_id)                    AS όλοι_οι_τίτλοι,
    MAX(price) KEEP (DENSE_RANK FIRST ORDER BY published_year) AS τιμή_παλαιότερου
FROM books;
```

Και ένα σοβαρό: η προεπιλεγμένη «κορνίζα» του παραθύρου όταν γράφεις `ORDER BY` μέσα σε `OVER`
είναι `RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`. Με ισοπαλίες στην τιμή ταξινόμησης,
το `RANGE` περιλαμβάνει **όλες** τις ισόβαθμες γραμμές — αποτέλεσμα διαφορετικό από το
`ROWS`. Όταν θέλεις «οι γραμμές μέχρι εδώ», γράψε ρητά `ROWS BETWEEN UNBOUNDED PRECEDING AND
CURRENT ROW`. Ισχύει και στην SQLite και στην PostgreSQL.

## 12.7 Απόδοση και ασφάλεια

**Πλάνο εκτέλεσης:**

```sql
EXPLAIN PLAN FOR
SELECT * FROM orders WHERE customer_id = 5;

SELECT * FROM TABLE(DBMS_XPLAN.DISPLAY);
```

Ψάχνεις `TABLE ACCESS FULL` σε μεγάλο πίνακα εκεί που περίμενες `INDEX RANGE SCAN`.

**Bind variables** — και για ταχύτητα και για ασφάλεια:

```sql
-- ✗ Ποτέ: SQL injection και γεμίζει τη μνήμη με χιλιάδες όμοια ερωτήματα
'SELECT * FROM customers WHERE email = ''' || είσοδος_χρήστη || ''''

-- ✓ Πάντα
SELECT * FROM customers WHERE email = :email;
```

Η Oracle αποθηκεύει το πλάνο ανά κείμενο ερωτήματος. Χωρίς bind variables, κάθε τιμή
δημιουργεί νέο πλάνο — γνωστό ως *hard parsing*, από τα συχνότερα προβλήματα απόδοσης σε
εταιρικά συστήματα.

## 12.8 Μια πλήρης μετάφραση

Η μηνιαία αναφορά του Μαθήματος 11, σε Oracle:

```sql
WITH ανά_μήνα AS (
    SELECT
        TRUNC(o.order_date, 'MM')            AS μήνας,
        COUNT(DISTINCT o.id)                 AS παραγγελίες,
        SUM(i.quantity * i.unit_price)       AS τζίρος
    FROM orders o
    JOIN order_items i ON i.order_id = o.id
    WHERE o.status = 'paid'
    GROUP BY TRUNC(o.order_date, 'MM')          -- η έκφραση, όχι το ψευδώνυμο
)
SELECT
    TO_CHAR(μ.μήνας, 'YYYY-MM')                        AS μήνας,
    μ.παραγγελίες,
    ROUND(μ.τζίρος, 2)                                 AS τζίρος,
    ROUND(π.τζίρος, 2)                                 AS πέρσι,
    ROUND((μ.τζίρος - π.τζίρος) * 100 / π.τζίρος, 1)   AS μεταβολή_pct,
    ROUND(SUM(μ.τζίρος) OVER (
        PARTITION BY EXTRACT(YEAR FROM μ.μήνας)
        ORDER BY μ.μήνας
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW), 2) AS ytd
FROM ανά_μήνα μ
LEFT JOIN ανά_μήνα π ON π.μήνας = ADD_MONTHS(μ.μήνας, -12)
ORDER BY μ.μήνας;
```

Σύγκρινέ το με την έκδοση SQLite στο [`bi/reports.sql`](../bi/reports.sql). Η δομή είναι
**πανομοιότυπη** — αλλάζουν μόνο τρεις συναρτήσεις. Αυτό είναι το μήνυμα ολόκληρου του
μαθήματος: μαθαίνεις SQL μία φορά, τη διάλεκτο τη συμβουλεύεσαι.

## 12.9 Οι άλλες διάλεκτοι σε μία γραμμή

| | PostgreSQL | MySQL | SQL Server |
|---|---|---|---|
| Πρώτα Ν | `LIMIT 10` | `LIMIT 10` | `TOP 10` / `OFFSET…FETCH` |
| Ημερομηνία τώρα | `NOW()` | `NOW()` | `GETDATE()` |
| Αν κενό | `COALESCE` | `IFNULL`/`COALESCE` | `ISNULL`/`COALESCE` |
| Ένωση κειμένου | `\|\|` | `CONCAT()` | `+` / `CONCAT()` |
| Μήνας | `DATE_TRUNC('month', d)` | `DATE_FORMAT(d,'%Y-%m')` | `DATEFROMPARTS(...)` |
| Χωρίς πίνακα | `SELECT 1;` | `SELECT 1;` | `SELECT 1;` |

## Περίληψη

Δεν χρειάζεται να τα απομνημονεύσεις. Χρειάζεται να **ξέρεις ότι υπάρχουν** — να μη σε
πιάσει απροετοίμαστο ένα `MINUS` ή ένα `CONNECT BY`, και να ξέρεις πού να κοιτάξεις.

Τα πέντε που αξίζει να θυμάσαι απ' έξω:
1. `dual`, `NVL`, `TO_DATE`/`TO_CHAR`
2. `''` = `NULL` και τα `NULL` ταξινομούνται τελευταία
3. ψευδώνυμο δεν μπαίνει στο `GROUP BY`
4. ημερομηνίες με `>= … AND < …`, ποτέ `BETWEEN`
5. `MINUS` αντί για `EXCEPT`
