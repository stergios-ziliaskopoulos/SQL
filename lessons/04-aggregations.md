# Μάθημα 4 — Συγκεντρωτικές συναρτήσεις και `GROUP BY`

## Στόχος

Να απαντάς σε ερωτήσεις τύπου «πόσα», «πόσο συνολικά», «κατά μέσο όρο ανά…».

---

## 4.1 Από πολλές γραμμές σε μία

Οι **συγκεντρωτικές συναρτήσεις** (aggregate functions) παίρνουν πολλές γραμμές και
επιστρέφουν μία τιμή:

```sql
SELECT
    COUNT(*)      AS πλήθος_βιβλίων,
    AVG(price)    AS μέση_τιμή,
    MIN(price)    AS φθηνότερο,
    MAX(price)    AS ακριβότερο,
    SUM(stock)    AS συνολικό_απόθεμα
FROM books;
```

Ένα αποτέλεσμα, μία γραμμή.

### `COUNT(*)` vs `COUNT(στήλη)` — σημαντική διαφορά

```sql
SELECT
    COUNT(*)         AS όλες_οι_γραμμές,      -- 25
    COUNT(author_id) AS με_συγγραφέα,         -- 23 (αγνοεί τα NULL)
    COUNT(DISTINCT author_id) AS διαφορετικοί_συγγραφείς
FROM books;
```

- `COUNT(*)` → μετρά **γραμμές**
- `COUNT(στήλη)` → μετρά **μη-`NULL` τιμές** της στήλης
- `COUNT(DISTINCT στήλη)` → μετρά **διαφορετικές** μη-`NULL` τιμές

Το ίδιο ισχύει παντού: **οι συγκεντρωτικές συναρτήσεις αγνοούν τα `NULL`**. Γι' αυτό ο
`AVG(rating)` σε 10 κριτικές όπου οι 3 είναι `NULL` διαιρεί με το 7, όχι με το 10.

## 4.2 `GROUP BY`: ένα αποτέλεσμα ανά ομάδα

```sql
SELECT
    category_id,
    COUNT(*)   AS πλήθος,
    AVG(price) AS μέση_τιμή
FROM books
GROUP BY category_id;
```

Σκέψου το ως εξής: το `GROUP BY` **στοιβάζει** τις γραμμές σε κουτιά (ένα ανά τιμή του
`category_id`) και μετά εφαρμόζει τη συνάρτηση σε κάθε κουτί χωριστά.

### Ο χρυσός κανόνας

> Κάθε στήλη του `SELECT` πρέπει είτε να είναι **μέσα σε** συγκεντρωτική συνάρτηση,
> είτε να αναφέρεται στο `GROUP BY`.

```sql
-- ✗ Το title διαφέρει μέσα στην ομάδα — ποιο να δείξει;
SELECT category_id, title, COUNT(*) FROM books GROUP BY category_id;
```

Η SQLite (σε αντίθεση με τις περισσότερες βάσεις) δέχεται σιωπηλά αυτό το ερώτημα και
επιστρέφει έναν **τυχαίο** τίτλο. Μην το εκμεταλλευτείς — είναι πηγή λαθών που περνούν απαρατήρητα.

Ομαδοποιείς και σε **πολλές** στήλες, ή και σε **υπολογισμό**:

```sql
-- Πόσα βιβλία ανά κατηγορία και δεκαετία έκδοσης
SELECT
    category_id,
    published_year / 10 * 10 AS δεκαετία,   -- 1987 → 1980 (ακέραια διαίρεση)
    COUNT(*)                 AS πλήθος
FROM books
GROUP BY category_id, δεκαετία
ORDER BY category_id, δεκαετία;
```

## 4.3 `HAVING`: φιλτράρισμα **ομάδων**

Το `WHERE` φιλτράρει **γραμμές πριν** την ομαδοποίηση.
Το `HAVING` φιλτράρει **ομάδες μετά** την ομαδοποίηση.

```sql
SELECT
    category_id,
    COUNT(*) AS πλήθος
FROM books
WHERE price > 10               -- 1. κράτα μόνο τα βιβλία άνω των 10 €
GROUP BY category_id           -- 2. ομαδοποίησε
HAVING COUNT(*) >= 3           -- 3. κράτα μόνο ομάδες με 3+ βιβλία
ORDER BY πλήθος DESC;
```

Στο `WHERE` **δεν** μπορείς να βάλεις `COUNT(*)`: τη στιγμή που τρέχει, οι ομάδες δεν
υπάρχουν ακόμα. Θυμήσου τη σειρά εκτέλεσης από το Μάθημα 1:

```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
```

## 4.4 Πρακτικά παραδείγματα

```sql
-- Πόσες παραγγελίες ανά κατάσταση;
SELECT status, COUNT(*) AS πλήθος
FROM orders
GROUP BY status
ORDER BY πλήθος DESC;
```

```sql
-- Τζίρος ανά έτος (μόνο πληρωμένες παραγγελίες)
SELECT
    STRFTIME('%Y', o.order_date)          AS έτος,
    COUNT(DISTINCT o.id)                  AS παραγγελίες,
    ROUND(SUM(i.quantity * i.unit_price), 2) AS τζίρος
FROM orders o
JOIN order_items i ON i.order_id = o.id     -- το JOIN έρχεται στο Μάθημα 5
WHERE o.status = 'paid'
GROUP BY έτος
ORDER BY έτος;
```

Πρόσεξε το `COUNT(DISTINCT o.id)`: μετά το `JOIN` κάθε παραγγελία εμφανίζεται τόσες φορές
όσες και οι γραμμές της, οπότε ένα σκέτο `COUNT(*)` θα μετρούσε **προϊόντα**, όχι παραγγελίες.

```sql
-- Μέση βαθμολογία ανά βιβλίο, μόνο για όσα έχουν τουλάχιστον 2 κριτικές
SELECT
    book_id,
    COUNT(*)              AS κριτικές,
    ROUND(AVG(rating), 2) AS μέση_βαθμολογία
FROM reviews
GROUP BY book_id
HAVING COUNT(*) >= 2
ORDER BY μέση_βαθμολογία DESC;
```

## 4.5 Δύο συνηθισμένες παγίδες

**1. `SUM` σε άδειο σύνολο δίνει `NULL`, όχι 0.**

```sql
SELECT COALESCE(SUM(quantity), 0) AS τεμάχια
FROM order_items WHERE book_id = 9999;
```

**2. Ο μέσος όρος των μέσων όρων δεν είναι ο μέσος όρος.**
Το `AVG(unit_price)` δίνει μέση τιμή **ανά γραμμή παραγγελίας**, όχι μέση τιμή ανά πωληθέν
τεμάχιο. Για το δεύτερο χρειάζεσαι σταθμισμένο μέσο:
`SUM(quantity * unit_price) / SUM(quantity)`.
